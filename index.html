03 Ответы на фильтр-вопросы

Опишите ваш опыт работы с нейросетями
Работаю с генеративным ИИ с момента появления первых доступных моделей. Прошёл путь от «попробовать ChatGPT» до построения продакшн-систем, где ИИ встроен в ежедневные рабочие процессы нескольких компаний. Пишу промпты, отлаживаю, обучаю на корпоративных данных, интегрирую через API. Слежу за рынком моделей и первым тестирую новые релизы.
Есть ли кейсы создания AI-ассистентов или автоматизации?
Да, и это основная часть моей практики. Создавал AI-виджеты для бизнеса (КП «Ботаника»), систему генерации визуального контента (ГК «Хорошо»), редакционный конвейер в отделе маркетинга. Отдельно — инструменты для аналитики рынка и финансового планирования. Все системы работают в реальных командах, а не в демо-режиме.
Какие инструменты ИИ используете чаще всего?
В работе с текстом — Claude (наиболее точный для длинных и сложных задач), GPT-4o для быстрых итераций. Для изображений — Midjourney + Stable Diffusion в зависимости от задачи. Для автоматизации — Python + API + n8n. Для агентских задач — Claude Code. Инструментарий меняется вместе с рынком.
Как бы вы построили систему генерации текстов для соцсетей публичного человека?
Шаг 1: Собрать массив аутентичных текстов — посты, интервью, публичные речи. Выявить лексику, ритм, любимые конструкции, темы. Шаг 2: Создать style guide + system prompt с детальным описанием голоса, примерами «так» и «не так». Шаг 3: Построить рабочий процесс: команда формирует месседж + контекст + цель поста, система генерирует 3–5 вариантов. Шаг 4: Итеративная доработка — каждый одобренный пост улучшает следующий. Финальный контроль всегда за человеком.
